# Dr. Ji Birthday Surprise

Interactive birthday website customized with:
- Recipient: Dr. Ji
- Date: 5 October
- Sender: Your future wife
- Personal message: You are very cute and such a gentleman, and I really appreciate it.
- Inside phrase: Chalray chalray waal

Upload index.html, style.css and script.js to GitHub, then import the repository into Vercel.
No build command is required.
